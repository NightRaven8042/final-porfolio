03 — Process

How I approach a project

  1. Plan: define the goal, audience, content, and required interactions.
  2. Build: create semantic HTML before adding layout and JavaScript.
  3. Test: check mobile and desktop widths, keyboard navigation, validation, and contrast.
  4. Improve: fix issues found during testing and keep the code organized.
